# Yormio branding assets

This folder is intentionally self-contained. The website does not depend on the mobile app repository.

Replace the placeholder files in this folder with the final official Yormio exports before production if you want image-based branding.

Suggested final asset names:

- `logo-primary.svg` or `logo-primary.png` — primary horizontal/wordmark logo
- `logo-light.svg` or `logo-light.png` — light mark for dark surfaces
- `logo-dark.svg` or `logo-dark.png` — dark mark for light surfaces
- `app-icon.png` — square app icon (recommended source: 1024×1024)
- `favicon.svg` / `favicon.png` — browser icon
- `og-image.png` — social preview image (recommended 1200×630)

Until these are replaced, the production pages use a CSS/text Yormio brand mark and do not display a fabricated logo.
